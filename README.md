# DynmapColorSync

Плагин для Paper/Spigot, синхронизирующий цвета городов/наций Towny с картой [Dynmap](https://github.com/webbukkit/dynmap) на сервере **VortexiaPolit**, дополняя [Dynmap-Towny](https://github.com/Xmufd/DynmapTowny).

## Зависимости

- **Dynmap**
- **Towny**
- Dynmap-Towny (опционально)

## Сборка

```
compile.bat
```
