# DynmapColorSync

Плагин для Paper/Spigot, синхронизирующий цвета городов/наций Towny с картой [Dynmap](https://github.com/webbukkit/dynmap) на сервере **VortexiaPolit**, дополняя [Dynmap-Towny](https://github.com/Xmufd/DynmapTowny).

## Зависимости

- **Dynmap**
- **Towny**
- Dynmap-Towny (опционально)

## Сборка

```
compile.bat
```

## Совместимость

- Minecraft **1.20.1**
- Ядро сервера: **Mohist 1.20.1** (плагин используется на сервере VortexiaPolit)
- Написан на Bukkit/Spigot API, поэтому может работать и на Paper/Spigot 1.20.x
